# 第一人称跟随角色相机计划书

> 状态：**计划中（未开工）**
> 目标：给可操控角色一套**第一人称（FPS）跟随相机**——相机以角色眼睛为锚点跟随，鼠标控制视角（偏航/俯仰），WASD 移动方向随相机朝向旋转，同时保持对第三人称/轨道等其他相机模式的兼容。
> 前置：角色控制器已落地（`CharacterVirtual`，脚本侧 `character.*`，`components` 里 `CharacterControllerComponent` 已含 `FacingYaw` 朝向与 `FrontAxis` 前向基准）；相机已有 Orbit/FPS 双模式（`Render/Camera.h`，FPS 模式自带 yaw/pitch 与 lookAt）；`input.mouse_delta()` 已注入脚本（`ScriptEngine.cpp:161`）；Play 态相机输入路由已通（`Scene.cpp:869` 主相机收 `OnEvent`）。
> 关联：`角色控制器CharacterVirtual计划书.md`（角色本体的能力与 API）、`动画状态机ASM计划书.md`（角色朝向与移动驱动）、`脚本输入系统计划书.md`（`input.*` 输入快照语义）、`编辑运行时物理分离计划书.md`（Play/Stop 生命周期）。

## 0. 一句话架构

```
鼠标移动 → Camera yaw/pitch（相机组件自身的 FPS 状态，引擎 Camera::OnMouseMove 更新）
        │
        ▼
相机 yaw → 角色朝向（每帧回写 CharacterControllerComponent.FacingYaw / Transform.Rotation）
        │
        ▼
WASD → 脚本按【相机 yaw】旋转输入 → character.set_move（世界空间水平期望速度）
        │
        ▼
物理子步 → CharacterVirtual 推进 → 角色 Transform 更新
        │
        ▼
相机位置 = 角色视点（脚底 + 旋转后的 EyeOffset）+ 朝向由 FPS 相机状态决定
```

**分工**：`Camera`（FPS 模式）负责"看"——yaw/pitch 姿态与 view 矩阵；角色控制器负责"走"——物理位移。两者在**每帧末尾由相机组件同步**（C++ 引擎侧做，脚本只负责读 `input.mouse_delta()` 转成 yaw/pitch 增量）。这是一条**单向数据流**：相机姿态决定角色朝向，角色位移反哺相机位置。

## 2. 组件定义（`GE/include/GE/Scene/Components.h`）

新增一个纯配置组件，挂在**角色实体**上（与 `CharacterControllerComponent` 同实体）：

```cpp
/**
 * @brief 第一人称跟随相机组件 —— 挂在角色实体上，让主相机跟随角色视点。
 *
 * 与 CameraComponent 的关系：本组件【不】自带 Camera 实例，而是标记
 * "场景里那台 Primary Camera 跟着我"。渲染仍用 CameraComponent 的实例，
 * 本组件只在每帧末尾把相机位置钉到角色视点、把相机朝向（鼠标控制）
 * 回写为角色朝向。实现见 FollowCameraSystem（Scene.cpp）。
 *
 * 配置（参与 .scene 序列化）：
 *   Enabled        总开关（关闭则相机不跟随，角色也不被相机驱动朝向）
 *   EyeOffset      视点偏移（角色局部系，绕 up 随朝向旋转；默认 (0,1.65,0) = 纯抬高）
 *   YawSpeed       鼠标偏航灵敏度（度/像素）
 *   PitchSpeed     鼠标俯仰灵敏度（度/像素）
 *   MinPitch/MaxPitch  俯仰上下限（度）
 *   InvertY        俯仰反转（可选，默认 false）
 *
 * 运行时（不参与序列化）：无——姿态全部存在 CameraComponent 的 Camera 里。
 */
struct FollowCameraComponent {
    bool  Enabled    = true;    ///< 总开关
    glm::vec3 EyeOffset = {0.0f, 1.65f, 0.0f}; ///< 视点偏移（角色局部系，绕 up 随朝向旋转；纯第一人称 = +Y 抬高）
    float YawSpeed   = 0.10f;   ///< 偏航灵敏度（度/像素）
    float PitchSpeed = 0.10f;   ///< 俯仰灵敏度（度/像素）
    float MinPitch   = -89.0f;  ///< 俯仰下限（度）
    float MaxPitch   = 89.0f;   ///< 俯仰上限（度）
    bool  InvertY    = false;   ///< 俯仰是否反转

    FollowCameraComponent() = default;
    FollowCameraComponent(const FollowCameraComponent &) = default;
    explicit FollowCameraComponent(const glm::vec3 &eyeOffset) : EyeOffset(eyeOffset) {}
};
```

**为什么挂在角色实体而非相机实体**：跟随逻辑需要读角色 Transform（锚点）与 `CharacterControllerComponent`（朝向），直接同实体访问最简单；相机实体可以是场景里那台 Primary Camera（含 `CameraComponent`），也允许是任意一台带 `CameraComponent` 的实体。这样**同一台主相机**在"没挂 FPS 组件的角色上"就是普通第三人称/轨道视角，挂了就变第一人称跟随——兼容现有场景。

## 3. 同步系统（`GE/src/Scene/Scene.cpp` 新增 `UpdateFollowCamera`）

在 `OnUpdate3D` 里**物理步进（`StepPhysics`）之后、`UpdateWorldTransforms` 之前**调用，**每帧一次**（非物理子步）：

```cpp
// 伪代码 —— 真实实现在 Scene.cpp，对齐 UpdateWorldTransforms 等既有节奏
// 调用时序（OnUpdate3D 子步骤，Scene.cpp:456）：
//   UpdateScripts → StepPhysics（物理子步消费 WishVelocity、FaceMovement 驱动朝向）
//   → UpdateFollowCamera（本系统：相机姿态 → 角色朝向 FacingYaw + 相机位置）
//   → UpdateAnimations → UpdateWorldTransforms → UpdateSkins → 渲染
// 时序依据：相机侧写的 FacingYaw 必须落在物理子步消费【之后】，下一帧物理才用
// 到；位置取角色最新脚底；世界矩阵在相机钉位后重算，渲染即用最新姿态。
void Scene::UpdateFollowCamera() {
    // 1. 取场景主相机（Primary 优先；沿用 GetPrimaryCameraEntity 的语义）
    Entity camEnt = GetPrimaryCameraEntity();
    if (!camEnt || !camEnt.HasComponent<CameraComponent>()) return;
    Camera &cam = camEnt.GetComponent<CameraComponent>().CameraInstance;

    // 2. 找挂 FPS 组件的角色实体（本场景约定至多一台；多台取第一个）
    auto view = m_Registry.view<TransformComponent, CharacterControllerComponent,
                                FollowCameraComponent>();
    if (view.empty()) return;
    entt::entity player = view.front();
    auto &tc  = view.get<TransformComponent>(player);
    auto &cc  = view.get<CharacterControllerComponent>(player);
    auto &fp  = view.get<FollowCameraComponent>(player);
    if (!fp.Enabled) return;

    // 3. 相机切到 FPS 姿态模式（若尚未）
    if (cam.GetMode() != Camera::Mode::FPS)
        cam.SetMode(Camera::Mode::FPS);

    // 4. 鼠标视角 → yaw/pitch（读场景输入快照的鼠标增量；只在 Play 态生效）
    if (IsPlaying()) {
        const glm::vec2 delta = m_InputState.GetMouseDelta();
        float yaw   = cam.GetYaw()   - delta.x * fp.YawSpeed;
        float pitch = cam.GetPitch() + (fp.InvertY ? -1.f : 1.f) * delta.y * fp.PitchSpeed;
        cam.SetYawPitch(yaw, pitch);   // SetYawPitch 内部已 clamp MinPitch/MaxPitch
    }

    // 5. 相机姿态 → 角色朝向：让角色脸朝相机看的方向。
    //    引擎只允许 CharacterVirtual 驱动朝向（UpdateCharacters 每子步
    //    cv->SetRotation 写回 Transform，PhysicsWorld.cpp:697）——相机侧若直接
    //    改 Transform.Rotation 会被下个子步覆盖。因此走组件通道：把相机 yaw
    //    换算成"模型前向应指向的水平角" target，然后复用 FaceMovement 的
    //    FacingYaw 限速逼近机制，让 CharacterVirtual 自己完成旋转。
    //    modelYaw = FrontAxis 局部前向轴（经 BaseRotation 旋转后）的水平朝向角，
    //               与 FaceMovement 的 globalFrontYaw（PhysicsWorld.cpp:689）同语义。
    const float kPi = 3.14159265358979f;
    // 单帧最大转向增量（度→弧度），与角色控制器的 FaceMovement 限速同思路；
    // 相机每秒 yaw 变化即限速上限，保证转身跟手、不因高灵敏度瞬转鬼畜。
    constexpr float kTurnMaxStep = glm::radians(720.0f);
    glm::vec3 configured(0.0f, 0.0f, 1.0f);
    switch (cc.FrontAxis) {
    case CapsuleAxis::X: configured = {1.0f, 0.0f, 0.0f}; break;
    case CapsuleAxis::Y: configured = {0.0f, 1.0f, 0.0f}; break;
    default:             configured = {0.0f, 0.0f, 1.0f}; break;
    }
    const glm::vec3 wv = cc.BaseRotation * configured;
    const float modelYaw = std::atan2(wv.x, wv.z);   // 模型前向固有朝向角
    const float target = glm::radians(cam.GetYaw()) - modelYaw;
    float diff = target - cc.FacingYaw;
    while (diff > kPi)  diff -= 2.0f * kPi;
    while (diff < -kPi) diff += 2.0f * kPi;
    cc.FacingYaw += std::clamp(diff, -kTurnMaxStep, kTurnMaxStep); // 限速逼近，不瞬转
    // 不直接调 cv->SetRotation：下个子步 UpdateCharacters 用 FacingYaw 重建旋转。

    // 6. 角色位置 → 相机位置（角色局部 EyeOffset 随朝向旋转后加到脚底；
    //    yaw 每帧已与相机同步，绕 up 旋转等于绕相机朝向系旋转 → 纯 +Y 不变，
    //    带水平分量自动成"过肩视角"：相机向后拉、随角色转身）
    const float yawRad = glm::radians(cam.GetYaw());
    const glm::vec3 offset(
        fp.EyeOffset.x * std::cos(yawRad) + fp.EyeOffset.z * std::sin(yawRad),
        fp.EyeOffset.y,
       -fp.EyeOffset.x * std::sin(yawRad) + fp.EyeOffset.z * std::cos(yawRad));
    cam.SetPosition(tc.Translation + offset);
}
```

**关键点**：
- **俯仰由相机管、偏航由相机管**，角色**只拿 yaw 转朝向**（俯仰不传给角色——角色不会低头，这是"跟随"而非"控制角色点头"）。若将来要角色模型低头（如持枪瞄准），再把 pitch 一起传，超初版范围。
- **水平偏移随朝向旋转**：相机相对角色后拉成过肩视角时，偏移绕 up 转（步骤 6 已把 yaw 烘焙进 offset）；纯第一人称 `EyeOffset=+Y` 时旋转无影响，行为不变。
- `Camera::SetYawPitch` 自带 `MinPitch/MaxPitch` clamp（Camera.cpp:91），组件里 MinPitch/MaxPitch 字段用于初始化相机 clamp（见 §4）。
- **渲染取用**：SceneLayer 在 Play 态已用 `GetPrimaryCameraEntity()` 的主相机渲染（SceneLayer.cpp:168），位置被钉到角色视点（步骤 6）后，画面自然变成第一人称。

## 4. 相机组件启动联动（初始化 + 生命周期）

挂在角色实体上的 FPS 组件在 **Play 进入时**需要把相机初始化到角色当前朝向，否则相机会从默认姿态"跳"到角色朝向：

- `Scene::Play()` 里，若存在 `FollowCameraComponent`：找到主相机，`cam.SetMode(FPS)`、用角色当前朝向初始化 `SetYawPitch`（从 `cc.FacingYaw` 换算度）、`SetPosition(脚底 + 旋转后的 EyeOffset)`、并把 `cam.MinPitch/MaxPitch` 设为组件字段（避免每帧 `SetYawPitch` clamp 时用 Camera 默认 ±89°）。
- `Scene::Stop()` 里，若相机是从 FPS 跟随切进来的，**保持**其当前姿态即可（Play 结束回到编辑，编辑相机独立于场景内容，不受影响）。

**相机实体与角色实体是否同一实体？** 都行：
- **同一实体**：角色实体加 `CameraComponent`（Primary=true）+ `FollowCameraComponent` + `CharacterControllerComponent`。最简单，一个实体搞定"玩家"。
- **分离实体**：相机实体带 `CameraComponent`，角色实体带 `CharacterControllerComponent` + `FollowCameraComponent`（后者指向"场景主相机"，靠 §3 步骤 1 的 Primary 查找，无需显式引用字段）。

初版推荐**分离实体**（相机不进物理、角色不含相机逻辑更清晰），计划书 §3 代码按此写。

## 5. 脚本：相机相对移动（`assets/scripts/fps_character_demo.lua`）

现有 `character_demo.lua` 是**世界空间** WASD。第一人称必须"按 W 朝相机前方走"。改法：脚本读相机 yaw（新增 `camera.get_yaw()` API 或复用 `transform.get_rotation` 读相机实体——见 §6 决策），把输入向量按 yaw 旋转：

```lua
-- fps_character_demo.lua —— 第一人称角色：鼠标视角 + 相机相对 WASD 移动
-- 前置：角色实体挂 CharacterControllerComponent + FollowCameraComponent
--       （相机实体另设，带 CameraComponent.Primary=true）
local M = {}

M.PUBLIC_FIELDS = {
    speed = { type = "number", default = 4.0 },
}

function M.OnUpdate(self, ts)
    local speed = public.get("speed") or 4.0

    -- 相机 yaw（度）：由 C++ 侧每帧从鼠标增量更新，脚本只读
    local yaw = camera.get_yaw()  -- 度；新增 camera.* API，见 §5 决策
    local ry = math.rad(yaw)

    -- WASD 输入（世界轴）
    local ix, iz = 0, 0
    if input.is_held(Key.W) then iz = iz - 1 end
    if input.is_held(Key.S) then iz = iz + 1 end
    if input.is_held(Key.A) then ix = ix - 1 end
    if input.is_held(Key.D) then ix = ix + 1 end

    -- 绕 Y 旋转到相机朝向系：W/S 沿前向，A/D 沿右向
    -- 前向 = (-sin yaw, 0, -cos yaw)，右向 = (cos yaw, 0, -sin yaw)
    local fx, fz = -math.sin(ry), -math.cos(ry)
    local rx, rz =  math.cos(ry), -math.sin(ry)
    local wx = fx * (-iz) + rx * ix
    local wz = fz * (-iz) + rz * ix

    -- 归一化并缩放（斜向移动不加速）
    local len = math.sqrt(wx * wx + wz * wz)
    if len > 0.0001 then
        wx, wz = wx / len * speed, wz / len * speed
    end
    character.set_move(wx, wz)

    -- 跳跃沿用角色控制器逻辑
    if input.just_pressed(Key.Space) then
        character.jump()
    end
end

return M
```

> 注：`camera.get_yaw()` 是新增 API（见 §6）；若不想加 API，可改为让脚本读**相机实体**的 `transform.get_rotation().y`（相机实体挂脚本）。初版建议加 `camera.*` 一组只读 API，语义更直接。

## 6. 脚本 API 增补（`GE/src/Scene/ScriptEngine.cpp`）

新增一组**只读**的相机查询，供脚本组合移动方向：

```lua
camera.get_yaw()      -- 主相机偏航（度）
camera.get_pitch()    -- 主相机俯仰（度）
camera.get_position() -- 主相机位置（可选，调试/观察用）
```

实现：`activeChar` 同款模式，改成查 `Scene::GetPrimaryCameraEntity()` 的 `CameraComponent`，读 `GetYaw()/GetPitch()/GetPosition()`。只读、无副作用，不破坏既有脚本。

**决策（开放）**：也可以不做 `camera.*`，让相机实体挂个 `ScriptComponent` + `transform.get_rotation()`。但这样脚本职责混杂（移动逻辑要顺着"相机实体"找）。倾向加 `camera.*`——干净、且为将来"相机震动/偏移/过肩视角"留了扩展位。

## 9. 与其他模式的关系（兼容性矩阵）

| 场景 | 行为 |
|---|---|
| 角色实体挂 FPS 组件 + 场景有 Primary Camera | 第一人称跟随（本次目标） |
| 角色实体**不**挂 FPS 组件 | 相机自由（Orbit/第三人称/手动），角色仍可用 `FaceMovement` 自身朝向逻辑 —— **现状行为不变** |
| FPS 组件 `Enabled=false` | 同"不挂"，相机不跟随、角色朝向回退 `FaceMovement` |
| 相机实体单独存在（Play 态无相机实体） | 回退编辑器相机（SceneLayer.cpp:178 现状逻辑），不受影响 |

**回归风险**：`UpdateFollowCamera` 只在"有 FPS 组件 + 有主相机"时激活，其余路径零改动 → 现有 `character_demo.lua`（世界空间移动）与 `character_asm_demo.lua`（ASM 联动）**继续可用**，只是它们的移动方向不会随相机转（那正是第一人称才需要的行为）。

## 10. 验收

- **跟随**：角色实体挂 `FollowCameraComponent` + 主相机，Play 后画面在角色眼睛高度（EyeOffset 生效），WASD + 鼠标移动，视角随鼠标转、位置随角色走（跳起时画面随之抬高）。
- **移动方向**：按 W 始终朝屏幕前方走（而非世界 -Z）；按 A/D 相对相机左右平移。
- **朝向回写**：角色模型前向（`FrontAxis`）随相机 yaw 转动（走 FacingYaw 通道，CharacterVirtual 驱动，限速转身不瞬转）；俯仰不传导（角色不低头）。观察视角看到角色转身。
- **回归**：不挂 FPS 组件的角色/相机场景行为不变；`character_demo.lua`、`character_asm_demo.lua` 不受影响；Play/Stop 反复切换相机姿态不跳变。
- **上坡/碰撞**：角色沿相机方向移动时仍受 CharacterVirtual 约束（上坡、被墙挡），相机跟随不出墙（位置锚定在角色脚底，天然不出墙）。

## 11. 风险与开放问题

1. **相机近平面穿模型**：视点在角色胶囊内，附近可能有角色自己的手臂/道具模型被近裁剪面切掉。初版不管（第一人称不渲染自己身体）；若将来要"可见身体"，需单独把身体网格从场景剔除或近平面分离绘制——超范围。
2. **朝向写入时机**：相机侧写 `FacingYaw` 的时机必须晚于物理子步消费（`UpdateFollowCamera` 排在 `StepPhysics` 之后，见 §3）。若两者同帧抢同一字段：物理按移动方向驱动、相机按视角驱动——时序保证相机赢。**初版明确 FPS 跟随优先**：挂 FPS 组件时，脚本 `fps_character_demo.lua` 的 WASD 已经按相机朝向旋转，移动方向与相机视角天然一致，`FaceMovement` 转到的目标角也收敛到同一值，基本不打架；若出现极端抖动，可再给 `FaceMovement` 加"FPS 模式下跳过"开关。
3. **鼠标捕获**：当前鼠标在视口内才路由输入（SceneLayer.cpp:244），离开视口/窗口鼠标视角停转。游戏化需"捕获鼠标 + 隐藏光标"，编辑器内体验优先不动。
4. **多角色多相机**：本场景假设"至多一个 FPS 角色 + 主相机"。多玩家/多视角需"相机实体显式引用角色实体"的字段，初版用"第一个 FPS 组件 + Primary 相机"的约定。
5. **Play/Stop 快照**：FPS 组件的姿态（相机 yaw/pitch）存在相机实例里，非 Transform，不进 `PlayTransformSnapshot`。反复 Play 相机姿态沿用上次——符合"编辑器相机独立"决策；若需每次 Play 重置朝向，在 §4 的 Play 初始化里统一用角色当前朝向即可（初版已如此）。
6. **物理帧 vs 渲染帧**：相机位置取角色最末子步 Transform，与动态体同步一致；渲染插值（若引入）需连相机一起插，留待未来。
7. **过肩视角的碰撞**：若用 `EyeOffset` 水平分量做第三人称过肩，相机被角色后方墙体挡住时需做**相机防穿墙**（射线回弹/弹簧），否则镜头钻墙。初版仅纯第一人称（EyeOffset=+Y，位置在角色胶囊内天然不出墙），过肩防穿墙留待独立小方案。
