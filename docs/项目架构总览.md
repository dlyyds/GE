# GE Game Engine 项目架构总览

> 本文档总结 GE 游戏引擎的整体架构，便于快速理解项目结构和各模块职责。

---

## 1. 顶层目录结构

```
GameEngine/
├── GE/                    # 引擎核心库（静态库）
│   ├── include/GE/        # 公开头文件
│   ├── src/               # 实现源文件
│   └── third_party/       # 第三方依赖库
├── sandbox/               # 示例/测试程序
│   ├── assets/            # 资源文件（着色器等）
│   └── Panels/            # ImGui 面板
├── assets/                # 项目级资源
├── docs/                  # 文档目录
├── CMakeLists.txt         # 主构建脚本
└── build.bat              # MSVC + Ninja 构建脚本
```

## 2. 引擎核心模块划分

### 2.1 Core（核心模块）
**目录**: `GE/include/GE/Core/` 和 `GE/src/Core/`

| 文件 | 职责 |
|------|------|
| `Application.h/.cpp` | 引擎主应用类，管理窗口、层、渲染循环 |
| `GEWindow.h` | 窗口抽象基类 |
| `GlfwWindow.h/.cpp` | GLFW 窗口实现（Windows 平台） |
| `Layer.h/.cpp` | 层抽象，用于场景/UI 分层 |
| `LayerStack.h/.cpp` | 层堆栈管理 |
| `Log.h/.cpp` | 日志系统（基于 spdlog） |
| `GEInput.h` | 输入抽象 |
| `KeyCodes.h` | 键盘按键码定义 |
| `MouseCodes.h` | 鼠标按键码定义 |
| `Timestep.h` | 时间步长计算 |
| `Timer.h` | 计时器 |
| `Base.h` | 基础宏定义（BIT、GE_BIND_EVENT_FN 等） |
| `EntryPoint.h` | 应用入口点宏 |
| `PlatformDetection.h` | 平台检测宏 |

**核心类关系**:
```
Application (单例)
├── 持有 Window (GlfwWindow)
├── 持有 LayerStack
├── 管理 ImGuiLayer
└── 主循环 Run()
```

### 2.4 Physics（物理系统）
**目录**: `GE/include/GE/Physics/` 和 `GE/src/Physics/`

| 文件 | 职责 |
|------|------|
| `PhysicsTypes.h` | 物理类型定义（RigidBodyType、BodyID） |
| `PhysicsWorld.h/.cpp` | 物理世界，封装 Jolt Physics |

**设计要点**:
- 基于 **Jolt Physics** 引擎
- 每个 `Scene` 拥有独立的 `PhysicsWorld`
- 固定 60Hz 物理步进 + 时间累加器
- 延迟刚体创建（组件添加完成后统一创建）
- 支持静态/运动学/动态刚体
- 支持 Box/Sphere 碰撞体

### 2.5 Scene（场景/ECS 系统）

| 文件 | 职责 |

**ECS 架构**（基于 **EnTT**）:

```

Entity (轻量级包装)
```

| 组件 | 用途 |

| `SpriteRendererComponent` | 2D 精灵渲染（纹理+颜色） |
| `MeshComponent` | 3D 网格渲染（网格+颜色） |
| `MaterialComponent` | 3D 材质（材质指针） |

### 2.6 Render（渲染系统 - 高层）

这是引擎最复杂的模块，分为高层渲染接口和底层 Vulkan 封装。

#### 2.6.1 Renderer（主渲染器）
| 文件 | 职责 |
|------|------|
| `Renderer.h/.cpp` | 统一渲染入口，管理 Vulkan 上下文和帧循环 |

**职责**:
- 持有 `VulkanContext`（全局 Vulkan 状态）
- 持有 `VulkanRenderContext`（帧/swapchain 管理）
- 持有 `Renderer2D`（2D 精灵渲染）
- 持有 `Renderer3D`（3D 网格渲染）
- 持有 `TextureManager` / `MaterialManager`
- 帧循环：`BeginFrame()` → 渲染 → `EndFrame()`

**静态访问接口**:
```cpp
static Renderer& Get();
static VulkanContext& GetVulkanContext();
static VulkanRenderContext& GetRenderContext();
static const VulkanSwapchain& GetSwapchain();
static VulkanCommandBuffer& GetFrameCmd();
static Renderer2D& Get2DRenderer();
static Renderer3D& Get3DRenderer();
static TextureManager& GetTextureManager();
static MaterialManager& GetMaterialManager();
```

---

#### 2.6.2 Renderer2D（2D 精灵渲染）
| 文件 | 职责 |
|------|------|
| `Renderer2D.h/.cpp` | 2D 精灵批处理渲染器 |

**特点**:
- 按纹理自动批处理
- 动态顶点分配（BufferPool）
- 支持 2D/3D 两种模式（深度测试开关）
- 支持纯色矩形和纹理精灵

**接口**: `BeginScene()` → `DrawSprite()` → `EndScene()`

---

#### 2.6.3 Renderer3D（3D 网格渲染）
| 文件 | 职责 |
|------|------|
| `Renderer3D.h/.cpp` | 3D 网格渲染器（Blinn-Phong 光照） |

**特点**:
- Blinn-Phong 光照模型
- 支持方向光 + 最多 8 个点光源 + 环境光
- 每个物体独立 UBO
- 纹理采样支持 mipmap LOD bias
- 深度测试 + 背面剔除

**接口**: `BeginScene()` → `DrawMesh()` → `EndScene()`

**UBO 结构**:
- **FrameUBO**（每帧）：projection / view / viewPos / 光照参数
- **ObjectUBO**（每个物体）：model / lodBias / color

**着色器资源绑定约定**:
```
Set 0: Frame UBO (每帧)        Binding 0: UniformBuffer
Set 1: Material Textures      Binding 0: CombinedImageSampler (Albedo)
Set 2: Object UBO (每物体)    Binding 0: UniformBuffer
```

---

#### 2.6.4 资源管理
| 文件 | 职责 |
|------|------|
| `Texture.h/.cpp` | 纹理封装（Image + View + Sampler） |
| `TextureManager.h/.cpp` | 全局纹理管理器（按路径去重缓存） |
| `Material.h` | 材质封装（纹理槽 + 标量参数） |
| `MaterialManager.h/.cpp` | 全局材质管理器 |
| `Mesh.h/.cpp` | 网格封装（顶点缓冲 + 索引缓冲） |
| `RenderTarget.h/.cpp` | 渲染目标（图像 + 视图） |
| `BufferPool.h` | 缓冲池（线性分配器） |
| `ResourceCaching.h` | 资源缓存哈希工具 |
| `SPIRVReflection.h/.cpp` | SPIR-V 着色器反射 |
| `Camera.h/.cpp` | 相机类（轨道模式 + FPS 模式 + 投影矩阵） |

**Mesh 支持**:
- 从 OBJ 文件加载（tinyobjloader）
- 从内存顶点/索引创建
- 内置几何体：Cube、Plane、Sphere、Quad
- 顶点格式：`Position(3) + Normal(3) + TexCoord(2)`

### 2.7 VulkanBase（Vulkan 底层封装）
**目录**: `GE/include/GE/Render/VulkanBase/` 和 `GE/src/Render/VulkanBase/`

对 Vulkan API 的完整 C++ 封装，基于 **Vulkan-Samples** 架构，使用 vulkan.hpp 绑定 + VMA 内存管理。

#### 2.7.1 核心上下文
| 类 | 职责 |
|----|------|
| `VulkanContext` | 全局 Vulkan 上下文（Instance + Device + Surface） |
| `VulkanRenderContext` | 帧/swapchain 管理器 |
| `VulkanInstance` | 创建 VkInstance，处理扩展和验证层 |
| `PhysicalDevice` | 选择 GPU，查询队列族和内存属性 |
| `VulkanDevice` | 逻辑设备（持有 ResourceCache，提供队列访问） |
| `VulkanSwapchain` | 管理 swapchain、图像和图像视图 |

```
VulkanContext
├── VulkanInstance
├── PhysicalDevice
├── vk::SurfaceKHR
└── VulkanDevice ──→ VulkanResourceCache

VulkanRenderContext
├── VulkanSwapchain
├── vector<VulkanRenderFrame>
└── VulkanSemaphorePool
```

---

#### 2.7.2 帧资源
| 类 | 职责 |
|----|------|
| `VulkanRenderFrame` | 每帧资源容器（BufferPool/CommandPool/DescriptorPool 等） |
| `VulkanCommandPool` | 命令池 |
| `VulkanCommandBuffer` | 命令缓冲 |
| `VulkanFencePool` | Fence 池 |
| `VulkanSemaphorePool` | Semaphore 池 |

```
VulkanRenderFrame (每帧一个)
├── map<usage, BufferPool[]> m_BufferPools
├── map<queueFamily, VulkanCommandPool[]> m_CommandPools
├── DescriptorPool[] m_DescriptorPools
├── DescriptorSet[] m_DescriptorSets (缓存)
├── VulkanFencePool m_FencePool
├── VulkanSemaphorePool m_SemaphorePool
├── RenderTarget m_RenderTarget
└── Reset()
```

## 6. 完整帧渲染流程

```
Application::Run()
│
└── [每帧]
    │
    ├── 1. 层更新 (Layer::OnUpdate)
    │    └── Scene::OnUpdate3D()
    │        ├── PhysicsWorld::Step()
    │        ├── Renderer3D::BeginScene()
    │        ├── [遍历实体] DrawMesh()
    │        ├── Renderer3D::EndScene()
    │        ├── Renderer2D::BeginScene()
    │        ├── [遍历实体] DrawSprite()
    │        └── Renderer2D::EndScene()
    │
    ├── 2. Renderer::BeginFrame()
    │    ├── VkAcquireNextImageKHR()
    │    ├── Begin command buffer
    │    └── Layout transition: Undefined → ColorAttachment
    │
    ├── 3. 层渲染 (Layer::OnImGuiRender)
    │    └── ImGui 绘制
    │
    └── 4. Renderer::EndFrame()
         ├── Layout transition: ColorAttachment → PresentSrc
         ├── End command buffer
         ├── Queue submit
         └── Present
```

## 8. 架构设计亮点

1. **分层设计**：Application → Layers → Scene → Renderer → VulkanBase，层次清晰
2. **资源管理**：全局去重缓存（VulkanResourceCache）+ 纹理/材质管理器 + BufferPool 线性分配 + 每帧资源池
3. **ECS 架构**：EnTT 作为底层，Entity 轻量包装，组件纯数据，系统通过 Scene::OnUpdate 调用
4. **物理集成**：Scene 持有 PhysicsWorld，组件驱动，延迟创建，固定步长 + 时间累加器
5. **Vulkan 封装**：基于 Vulkan-Samples 架构，vulkan.hpp 绑定，VMA 内存管理，Builder 模式，动态渲染
