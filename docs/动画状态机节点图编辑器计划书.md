# 动画状态机 ASM 节点图编辑器实现计划书

> 状态：**计划中（未开工）**。前置已完成：动画状态机 ASM 已落地（`AnimStateMachineComponent` 数据模型 + 求值内核 + 序列化 + 编辑器列表式面板 `DrawAnimStateMachine` + Lua 脚本桥 `anim.*`）。仓库已带 `imgui-node-editor` 0.9.3 完整源码（`GE/third_party/imgui-node-editor-0.9.3/`），尚未接入构建。
> 目标：把 ASM 的**列表式编辑**升级为**节点图可视化编辑**——状态画成节点、转换画成连线，支持拖拽连线建转换、点选节点/连线改属性、当前状态实时高亮。对应 `docs/动画状态机ASM计划书.md` §4 路线图 **D-11**。
> 定位：**纯编辑器侧改造**，只换 ASM 的编辑界面；**不改数据模型、不改求值内核、不改序列化格式**。图编辑器与既有列表面板（`SceneHierarchyPanel::DrawAnimStateMachine`）读写同一份 `AnimStateMachineComponent`，两者共存、实时互通。

---

## 0. 一句话架构

```
ASMGraphLayer（独立停靠窗口）持有一个 ed::EditorContext（imgui-node-editor）
  每帧：取 HierarchyLayer 的当前选中实体 → Reg().try_get<AnimStateMachineComponent>
        把 states 画成节点、transitions 画成连线（from==SIZE_MAX 画成虚拟 ANY 节点）
        支持拖拽连线建转换、点选节点/连线在侧栏编辑属性、Del 删除
  实时高亮：asmc->current 所在节点描边/着色，asmc->stateTime 显示
  位置持久化：ed::NodeId = (实体, 状态下标) 唯一编码 → 库自带 SettingsFile 落盘
```

**三个"不改"**：不改 `AnimStateMachineComponent` 数据模型（不加图元数据字段）；不改 `AnimationSystem::UpdateAnimations` 求值内核；不改 `SceneSerializer` 序列化格式（旧 `.scene` 无图数据，照常加载，节点自动布局）。

## 1. 现状盘点与差距定位

| 能力 | 现状（列表式面板 `DrawAnimStateMachine`） | 节点图差距 |
|---|---|---|
| 看结构 | 两张表（状态表 / 转换表）滚动浏览 | 一眼看清状态-转换拓扑 |
| 建状态 | 表单按钮 | 空白处右键/按钮添加，节点自动摆放 |
| 建转换 | From/To 下拉 + 条件列表 | **拖拽连线**（源状态输出引脚 → 目标状态输入引脚） |
| 删转换 | 表单删除按钮 | 选中连线 Del 删除 |
| 改属性 | 行内输入 | 点选节点/连线，在面板内嵌小属性区编辑（clip/loop/speed/blendSec/条件） |
| 实时状态 | 文本"当前状态 X / stateTime Ns" | 当前状态节点高亮描边 + 节点内显示 stateTime |
| 参数调试 | 已有滑条/开关 | 保留在列表面板，图面板只做节点/连线编辑 |

## 2. 总体设计

### 2.1 图↔数据模型映射

| 图元素 | 数据 |
|---|---|
| 节点 | `states[i]`（`AnimStateDef`：name / clipName / loop / speed） |
| 虚拟节点 ANY | `transitions[].from == SIZE_MAX` 的公共源；不映射进 `states`，仅图内虚拟展示 |
| 连线 | `transitions[j]`（`from→to`；`from==SIZE_MAX` 的连线从 ANY 节点的输出引脚出发） |
| 连线上标签 | 转换属性：`blendSec` + 条件数（如 `0.25s · 1条条件`） |
| 高亮 | `asmc->current` 状态节点描边 + 节点内显示 `stateTime` |

### 2.2 节点 ID 与位置持久化

- **NodeId / PinId / LinkId 编码**：三者都是 `uintptr_t`。为避免多实体共享同一编辑器上下文时撞 ID，统一编码为 `(实体 id << 16) | 状态下标`（实体 id 取 `entt::id_type(entity)`）；PinId 再 `| 0x8000`（输出）/ `| 0x4000`（输入）区分方向；LinkId 用转换下标。LinkId 每帧按 `transitions` 重建。
- **位置持久化**：利用库自带 `ed::Config.SettingsFile`（每帧自动增量保存节点坐标）。因为 NodeId 已含实体 id 与状态下标，不同实体/不同状态互不冲突。**已知限制**：状态下标是 NodeId 一部分，在状态列表中间插入/删除会导致后续状态坐标错位——提供「重新布局」按钮（`ed::NavigateToContent` + 按声明序重置坐标）兜底；接受为 v1 局限。
- **首帧布局**：首次见到某状态（`GetNodePosition` 返回原点）时按声明序网格摆放，避免全部叠在原点。

### 2.3 面板结构

```
┌─ "动画状态机图"（停靠窗口）─────────────────────────────┐
│ 顶栏：实体名 + ASM 开关(Checkbox) + [重新布局]          │
│ 主画布：ed::Begin("ASM Graph") / ed::End()             │
│   · 每个状态一个 ed::BeginNode/EndNode                  │
│     · 标题行：状态名 + 初始状态★ / 当前状态▶ 标记        │
│     · 输出引脚(右侧)：作为转换源                          │
│     · 输入引脚(左侧)：作为转换目标                         │
│     · 选中时下方显示 clip/loop/speed 快速编辑（可选）      │
│   · ANY 虚拟节点（固定角落）                             │
│   · 连线：ed::Link（来源→目标，颜色按 from==ANY 区分）    │
│ 底部：选中节点/连线的属性编辑区（见 2.4）                  │
└────────────────────────────────────────────────────────┘
```

### 2.4 交互设计

**建转换（拖拽连线）**：`ed::BeginCreate` → `QueryNewLink` → 校验（输出引脚必须在 `states` 源状态或 ANY，输入引脚是目标状态）→ `AcceptNewItem` → push `AnimTransitionDef{from, to, 0.25f, {}}`（from 来自输出引脚所在状态，输出引脚是 ANY 的则 `SIZE_MAX`）。

**删转换**：`ed::BeginDelete` → `QueryDeletedLink` → 从 `transitions` 删除 → `AcceptDeletedItem`。节点删除走 `QueryDeletedNode` → 复用列表面板的「删除状态 + 重编号 transitions」逻辑（从 `DrawAnimStateMachine` 抽成公共函数或在图面板内复制，见 §3）。

**选中编辑**：用 `GetSelectedNodes / GetSelectedLinks` 取当前选中；在面板底部渲染属性区：
- 选中**状态**：`name` 输入 + clip 下拉（读同实体 `AnimationComponent`，逻辑同 `DrawAnimStateMachine`）+ loop 勾选 + speed 输入 + 设初始状态按钮。
- 选中**转换**：`blendSec` 输入 + 条件编辑器（复用列表面板的条件字段：类型下拉 + 参数 + 比较 + 阈值 + 期望值 + 增删行）。
- 未选中：提示文本。

**当前状态高亮**：每帧读 `asmc->current` / `asmc->enabled`；当前状态节点标题栏换色描边，节点内 `ImGui::Text("stateTime %.2f", asmc->stateTime)`。

### 2.5 与既有面板/选中机制的接线

- **选中来源**：照 `GizmoController` 的模式——`ASMGraphLayer` 构造时收 `HierarchyLayer*`，每帧 `GetSelectedEntity()` 轮询（`EditorApp.cpp:27` 同款）。
- **共享场景**：`ASMGraphLayer(std::shared_ptr<EditorContext> context, HierarchyLayer* hierarchy)`；每帧从 `context->Scene->Reg()` 取组件。场景被替换（新建/加载）时面板 `SetContext` 同款重绑（参照 `HierarchyLayer.cpp:28-35`）。
- **与列表面板互通**：两者都直接改同一组件（图面板改 `states/transitions`，列表面板显示同一对象），天然实时同步；无事件系统需要。未选中实体 / 选中实体无 ASM 组件 → 图面板显示占位提示。

### 2.6 库接入（CMake）

在根 `CMakeLists.txt` 的 `imgui` 目标之后新增独立静态库目标（库自带 `examples/` 下的 CMake 只服务示例，不复用）：

```cmake
add_library(imgui_node_editor STATIC
    ${CMAKE_SOURCE_DIR}/GE/third_party/imgui-node-editor-0.9.3/crude_json.cpp
    ${CMAKE_SOURCE_DIR}/GE/third_party/imgui-node-editor-0.9.3/imgui_canvas.cpp
    ${CMAKE_SOURCE_DIR}/GE/third_party/imgui-node-editor-0.9.3/imgui_node_editor.cpp
    ${CMAKE_SOURCE_DIR}/GE/third_party/imgui-node-editor-0.9.3/imgui_node_editor_api.cpp)
target_include_directories(imgui_node_editor PUBLIC
    ${CMAKE_SOURCE_DIR}/GE/third_party/imgui-node-editor-0.9.3)
target_link_libraries(imgui_node_editor PUBLIC imgui)   # 复用引擎现有 imgui 目标
```

然后 `target_link_libraries(${Editor_NAME} PRIVATE ... imgui_node_editor)`。**兼容性已核实**：库 0.9.3 内部自带的 splitter 辅助函数（`ImDrawListSplitter_Grow` 等在 `imgui_node_editor.cpp` 内定义）与引擎 imgui 1.92.8 的结构体（`ImDrawChannel/ImDrawListSplitter/ImDrawList::_Splitter`，`imgui.h:3357-3435`）匹配，可直接编译；`imgui_extra_math.h` 的版本分支（`IMGUI_VERSION_NUM < 18955`）在 1.92.8 走现代分支。

## 3. 分阶段实施

### 阶段 A：库接入 + 空面板窗口

- A1. 根 `CMakeLists.txt`：新增 `imgui_node_editor` 目标（见 2.6），链接进 `GE_Editor`。
- A2. 新增 `GE_Editor/src/Panels/ASMGraphPanel.h/.cpp`：`ASMGraphPanel(std::shared_ptr<EditorContext>, HierarchyLayer*)`，每帧 `OnImGuiRender` 打开停靠窗口；无选中实体 / 无 ASM 组件 → 占位提示。
- A3. 新增 `GE_Editor/src/ASMGraphLayer.h/.cpp`：薄 Layer 包装（照 `ResourceLayer` 模式），`OnImGuiRender` 转发面板，`OnDetach` 解绑。
- A4. `EditorApp.cpp`：`PushLayer` 加入 `ASMGraphLayer(context, hierarchy_layer.get())`。
- A5. `DockSpaceLayer.cpp::BuildDefaultLayout`：注册「动画状态机图」窗口（右列与 Resource 并列 tab，或底部）。

**退出标准**：`build.bat` 编译通过；启动编辑器出现新窗口；选中 FPS 角色实体时不再显示占位。

### 阶段 B：只读图渲染

- B1. 面板持有 `ed::EditorContext`（`CreateEditor`，`Config.SettingsFile = "asm_graph.json"`）；每帧 `ed::Begin("ASM Graph") / ed::End()`。
- B2. 把 `states` 画成节点：`BeginNode(nodeId)` + 标题（名字 + 初始★/当前▶ 标记）+ 输出/输入引脚 + `EndNode`；首帧或 `GetNodePosition` 为原点时按声明序网格布局。
- B3. 虚拟 ANY 节点：固定摆放（如画布左上），带一个输出引脚；`transitions[].from==SIZE_MAX` 的连线从它出发。
- B4. 画连线：`ed::Link(linkId, 源pin, 目标pin, 颜色)`；`from==ANY` 用不同颜色/虚线。
- B5. 实时高亮：当前状态节点标题栏描边 + 节点内显示 `stateTime`。

**退出标准**：选中带 ASM 的角色实体，节点图正确显示全部状态与转换（含 ANY 连线）；Play 运行时当前状态节点实时高亮、stateTime 刷新；节点可拖动、缩放/平移画布正常；位置随设置文件跨启动保持。

### 阶段 C：交互编辑

- C1. **拖拽建转换**：`BeginCreate/EndCreate` → `QueryNewLink` → 校验后 push `AnimTransitionDef`（from 由输出引脚状态决定，ANY 引脚 → `SIZE_MAX`）。
- C2. **删除**：`BeginDelete/EndDelete`：删连线 → 从 `transitions` 移除；删节点 → 复用列表面板的「删状态 + 重编号 transitions」逻辑（抽公共函数到 `ASMGraphPanel` 或面板间共享）。
- C3. **选中编辑**：底部属性区——状态（name/clip/loop/speed/设初始状态）+ 转换（blendSec + 条件列表，条件字段照抄列表面板）。
- C4. 「重新布局」按钮：`ed::NavigateToContent` + 按声明序重置坐标。

**退出标准**：拖拽两状态引脚间能建转换且序列化后仍在；选中连线改 `blendSec`/条件即时生效；Del 删连线/状态后 `transitions` 引用正确（无悬空 from/to）；与列表面板同组件实时互通（改图→列表同步，改列表→图同步）；保存→加载场景后图结构与 ASM 数据一致。

### 阶段 D：打磨与兜底

- D1. 多实体切换：切选中实体时图内容切换，节点位置各自保持（NodeId 已含实体 id）。
- D2. 边界：空 `states` / 全 ANY 转换 / 指向不存在状态的 `from/to`（加载自旧场景）→ 图不崩、显示占位/警告。
- D3. 与列表面板功能对齐核对：初始状态、状态机开关、状态增删后 current/stateTime 的合理性（沿用列表面板既有处理）。

**退出标准**：§7 全部验收项通过。

| 风险 | 等级 | 对策 |
|---|---|---|

## 9. 决策记录（编码前拍板）

**9.1 库选择 —— ✅ 已定：接入仓库自带 `imgui-node-editor` 0.9.3**
- 已验证与引擎 imgui 1.92.8 兼容（splitter 辅助函数库内自带、结构体匹配）。自带成熟画布/缩放/拖拽/选中/删除交互，比手写自绘（贝塞尔 + 自实现 hit-test）省大量工作且体验好。代价：新增 4 个 cpp 编译目标。

**9.2 图元数据不入数据模型 —— ✅ 已定：不加字段到 `AnimStateMachineComponent`**
- 节点坐标靠库 SettingsFile（NodeId 含实体 id + 状态下标）；状态/转换增删仍是既有 `states/transitions` 操作。保持数据模型与序列化零改动，图编辑器可整体摘除不影响运行时。

**9.3 NodeId 编码 —— ✅ 已定：`(实体 id << 16) | 状态下标`，PinId 用高位 bit 分方向**
- 解决多实体共享编辑器上下文撞 ID；代价是中间增删状态坐标错位，用「重新布局」按钮兜底。

**9.4 与列表面板关系 —— ✅ 已定：两者并存、读写同一组件、实时互通**
- 不替换 `DrawAnimStateMachine`（它仍是参数调试与精细编辑的入口）；图面板聚焦拓扑与连线。删除状态的重编号逻辑抽公共函数复用。

**9.5 交互范围 —— ✅ 已定：v1 支持拖拽建转换 / Del 删 / 点选底部编辑属性；条件编辑在底部属性区进行（不做连线上多段条件直连）**
- 把「一条转换多条条件」的画布直连推迟到路线图，避免 v1 引入多边语义复杂度。

## 10. 与既有链路的关系（改动面收敛）

```
SceneHierarchyPanel::DrawAnimStateMachine（列表式，既有，保留）
        └── 读写 ──┐
                   ▼
      AnimStateMachineComponent（states / transitions / conditions / floats / bools / triggers）
                   ▲
ASMGraphPanel（节点图，新增）── 读写 ──┘   ← 新增 imgui_node_editor 目标（仅 GE_Editor 链接）

运行时求值 AnimationSystem::UpdateAnimations 读同一组件，零改动
序列化 SceneSerializer 读同一组件，零改动
```

`OnUpdate3D` 时序、求值内核、序列化格式、`.geanim` 全部不变。本计划是**纯编辑器视图层新增**：库目标只被 `GE_Editor` 链接，`GE` 引擎库不感知 `imgui_node_editor`，运行时与数据层完全隔离。
